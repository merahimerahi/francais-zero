# منصة "فرنسيتي" التعليمية 🇫🇷

منصة تفاعلية متكاملة لتعلّم اللغة الفرنسية من الصفر وحتى الاحتراف (من المستوى 0 إلى C2)، مصممة خصيصاً للناطقين باللغة العربية، ومستوحاة من هيكلية ومنهجية المنصات العالمية الشهيرة مثل W3Schools.

## مميزات المنصة
* **ثنائية اللغة ودعم تام للاتجاهين:** واجهة عربية كاملة (RTL) مع نصوص فرنسية دقيقة بالتشكيل والاتجاه الصحيح (LTR).
* **محرك نطق صوتي متكامل:** يعتمد على تقنية المتصفح الصوتية (`WebSpeech API`) لنطق الحروف والكلمات الفرنسية بلهجة طبيعية `fr-FR`.
* **نظام تفاعلي متقدم للدروس والحصص:** قائمة جانبية قابلة للطي والبحث السريع، مع تتبع دقيق للتقدم وحفظه تلقائياً في `localStorage`.
* **تمارين فورية مع تقييم ذكي:** أسئلة اختيار من متعدد مع تغذية راجعة فورية وشروحات تعليمية.
* **تصميم متجاوب بالكامل (Responsive):** يعمل بسلاسة على الحواسيب، الأجهزة اللوحية، والهواتف الذكية مع قائمة منزلقة (Mobile Drawer).

## هيكل المشروع
- `index.html`: الصفحة الرئيسية للمنصة واختيار المستويات.
- `level.html`: صفحة التعلم التفاعلية وعرض محتوى الدروس.
- `css/style.css`: الأنماط والتصميم العصري المتقدم.
- `js/levels.js`: قاعدة بيانات المستويات (0 إلى C2).
- `js/lessons.js`: المنهج التفصيلي والحصص والتمارين.
- `js/level-page.js`: منطق التصفح والتفاعل وإدارة الصوت والتقدم.
- `js/main.js`: التوجيه والقوائم العامة.

## كيفية التشغيل
قم بفتح ملف `index.html` في أي متصفح ويب حديث لتشغيل المنصة مباشرة دون الحاجة لأي خادم خلفي أو مكتبات خارجية معقدة.
